Overview

PMLD Smart Agro Melon is an academic IoT greenhouse monitoring simulation. The system works with simulated temperature, humidity, soil moisture, and light readings, processes the data in a Laravel backend, evaluates thresholds, logs alerts, and exposes dashboard data for monitoring and virtual device control.

Objective

Build a local greenhouse-monitoring simulation that can generate sensor readings, detect threshold conditions, record alerts, present historical and summary data, and control virtual greenhouse devices.

My Role

Back End. My planned backend scope covers database models and seed data, the sensor-data simulator, threshold and alert logic, dashboard aggregation, API responses, virtual device controls, background generation, reporting support, and local-server deployment setup.
